# EcoCollect
# 🌍 E-Waste Management Web App  
*A modern Next.js + TypeScript web application for responsible electronic waste handling.*

---

## 📌 Overview  
This project is a beautifully designed, fast, and modern web application that helps users **identify e-waste, find nearby collectors, and request pick-ups** (prototype).  
It promotes awareness, sustainability, and responsible disposal of electronic waste.

---

## ✨ Features

### 🔍 Nearby Collector Finder  
Find government-authorized or private **e-waste collection centers** around your location.

### ♻️ E-Waste Identifier  
A smart tool that helps users quickly determine whether their device qualifies as **e-waste**, recyclable, or reusable.

### 🚚 Pickup Request Prototype  
A non-functional but fully designed **UI/UX prototype** where users can submit a pickup request.

### 🎨 Clean & Modern UI  
Built with reusable components, smooth styling, and a responsive layout using:
- **Next.js (App Router)**
- **TypeScript**
- **HTML + CSS**
- **Modern UI patterns**

## 🚀 Getting Started

### **1. Clone the repository**
```bash
git clone https://github.com/ShabdVasudeva/EcoCollect.git
cd EcoCollect
```
### **2. Install dependencies**
```bash
npm install
```
### **3. Run in development mode**
```bash
npm run dev
```
