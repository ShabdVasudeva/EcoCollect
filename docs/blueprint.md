# **App Name**: EcoCollect

## Core Features:

- E-Waste Guide: Interactive guide categorizing e-waste and explaining their environmental impact.
- Recycling Locator: Map-based locator to find nearby e-waste recycling centers.
- Pickup Scheduling: Streamlined form for scheduling e-waste pickups.

## Style Guidelines:

- Primary color: Fresh green (#8FBC8F) to evoke environmental consciousness.
- Background color: Light green (#E5F3E5), a desaturated tint of the primary color.
- Accent color: Deep blue (#4682B4) for contrast and a sense of responsibility.
- Body and headline font: 'PT Sans' for a clean, modern and approachable look.
- Use vector-based icons with rounded edges to represent different types of e-waste and recycling processes.
- Subtle transitions and animations to enhance user engagement.
- Clean and modern layout with clear hierarchy for easy navigation.
